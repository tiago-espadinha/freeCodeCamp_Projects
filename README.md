# freeCodeCamp Projects Repository

This repository contains my solutions to various projects and challenges from the freeCodeCamp curriculum. Each directory represents a different certification or topic area.

## Directory Structure

- `responsive_web_design/` - Projects from the Responsive Web Design certification
- `legacy_responsive_web_design/` - Earlier responsive web design projects
- `javascript/` - JavaScript algorithms and data structures projects
- `legacy_js_algorithms_data_structs/` - Legacy JavaScript projects
- `frontend_libraries/` - Projects using frontend libraries (React, Redux, etc.)
- `python/` - Python programming projects
- `rosetta_code/` - Solutions from Rosetta Code challenges

## Certifications Covered

1. Responsive Web Design
2. JavaScript Algorithms and Data Structures
3. Frontend Libraries
4. Python Programming
5. Additional coding challenges

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- React
- Python
- Various APIs and libraries as required by individual projects

## How to Use

Each project directory contains its own index.html (for web projects) or source code files. Open the HTML files in a browser to view web projects, or run the Python/JavaScript files as appropriate for each project.

These projects were completed as part of the freeCodeCamp curriculum and represent my solutions to the assigned challenges. The repository serves as a portfolio of my learning progress and coding abilities.
